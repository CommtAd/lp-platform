# design-refs/pattern-c — ブライダルフェア（パターンC）の参照画像

`pattern-a/` と同じ扱いのフォルダ。パターンCの検収基準となる参照画像をここに置く。

- 参照画像は**見た目の合意を取るためのもの**。デザインは参考にしてよいが、
  **画像素材そのものをLPに流用しない**（CLAUDE.md 規約11）。
  実際の画像は式場から受領した素材、または `ImageSlot` のプレースホルダを使う。
- Claude Design の出力コードは直接持ち込まない。`_base-c/` からの差分適用で制作する（規約9）。
- コード化後のデザイン修正はコード側で行う。Claude Design には戻らない（規約10）。

制作時の読む順序: `docs/implementation-brief-02.md` → このフォルダの参照画像 → `_base-c/config.ts`。
